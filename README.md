# Java Basic Projects - Progressive Learning Path

A comprehensive collection of 12 Java projects demonstrating skills from basic fundamentals to Object-Oriented Programming (OOP).

## Project Overview

### Level 1: Basics
1. **Hello World & Console IO** - Basic output, variables, data types
2. **Calculator** - Arithmetic operations, conditionals, user input
3. **Number Guessing Game** - Loops, conditions, random numbers

### Level 2: Control Flow & Functions
4. **Temperature Converter** - Methods, type conversion, modular code
5. **Grade Management System** - Arrays, loops, multiple functions
6. **Prime Number Checker** - Complex logic, nested loops

### Level 3: Collections & Algorithms
7. **To-Do List** - ArrayList, CRUD operations, user menu
8. **Simple Bank System** - Collections, data management, state
9. **Sorting & Searching** - Arrays, algorithms, efficiency

### Level 4: OOP Fundamentals
10. **Bank Account Manager** - Classes, objects, encapsulation, methods
11. **Library Management System** - Inheritance, polymorphism, relationships
12. **E-Commerce Product Catalog** - Multiple classes, composition, advanced OOP

---

## How to Compile and Run

```bash
cd "path/to/project"
javac *.java
java MainClassName
```

Each project is self-contained with clear documentation.
