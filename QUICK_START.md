## 🔍 Debugging Help

### Common Errors & Fixes

| Error | Cause | Fix |
|-------|-------|-----|
| `javac not found` | JDK not installed/PATH issue | Install JDK, add to PATH |
| `class not found` | Wrong directory or filename | Check file name and location |
| `cannot find symbol` | Variable/method typo | Check spelling and scope |
| `InputMismatchException` | Wrong input type | Validate user input |
| `NullPointerException` | Null object access | Add null checks |
