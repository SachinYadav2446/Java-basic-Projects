================================================================================
COMPILATION & EXECUTION:
================================================================================

COMPILE:
  javac FileName.java

EXECUTE:
  java ClassName

EXAMPLE:
  cd 01_HelloWorld
  javac HelloWorld.java
  java HelloWorld

COMMON ISSUES & SOLUTIONS:
  Issue: "javac command not found"
  → Install JDK (Java Development Kit)
  → Add JDK bin folder to system PATH

  Issue: "Class not found"
  → Verify you're in the correct directory
  → Check if class name matches file name
  → Ensure file has .java extension

  Issue: "Cannot find symbol"
  → Check for typos in variable/method names
  → Verify variable scope (declared before use)
  → Check method signatures
